# Chain-Mind Auditor

Chain-Mind Auditor is a Python-based blockchain auditing tool built using Web3.py.

## Features

- Connects to the Ethereum Sepolia test network
- Scans recent blockchain blocks
- Checks transaction values
- Identifies zero-value transactions
- Detects smart contract addresses
- Identifies contract interactions
- Flags high-value transactions for review
- Provides a summary of the audit

## Technologies Used

- Python
- Web3.py
- Ethereum Sepolia
- Alchemy API
- python-dotenv
